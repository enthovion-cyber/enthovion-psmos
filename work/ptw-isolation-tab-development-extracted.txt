================================================== BACKEND RULES
==================================================
1. Permit activation rule: If permit.isolation_required = true:
2. At least one isolation point must exist.
3. Every required isolation point must be Confirmed.
4. If second_person_verification_required = true, it must be Verified.
5. Permit activation must be blocked if not complete.
6. Permit closure rule: If any isolation point is Confirmed or Verified:
7. Permit cannot close until all points are De-Isolated.
8. If removal verification required, it must be Removal Verified.
9. Permission rules: Only users with permission can:
10. ptw.isolation.add
11. ptw.isolation.edit
12. ptw.isolation.delete
13. ptw.isolation.confirm
14. ptw.isolation.verify
15. ptw.isolation.deisolate
16. ptw.isolation.certificate.generate
17. Signature rules: Confirmation, verification, de-isolation, and removal verification require electronic
signature.

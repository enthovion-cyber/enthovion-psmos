================================================== MOC STATUSES
==================================================
Support:
• Draft
• Submitted
• Under Review
• Approved
• Implementation
• Pending PSSR
• Ready For Startup
• Closed
• Rejected
• Cancelled
• Overdue Temporary Change
Lifecycle rules:
• Draft → Submitted
• Submitted → Under Review
• Under Review → Approved / Rejected
• Approved → Implementation
• Implementation → Pending PSSR if PSSR required
• Implementation → Ready For Startup if no PSSR required
• Pending PSSR → Ready For Startup after PSSR complete
• Ready For Startup → Closed after closure checklist complete
• Temporary change can become Overdue Temporary Change if expiry passes
• Closed is final
• Cancelled is final
Hard blockers:
• Cannot approve if required impact assessment incomplete.
• Cannot approve if risk ranking incomplete.
• Cannot approve High/Critical without engineering package or approved justification.
• Cannot move to Ready For Startup if required actions are incomplete.
• Cannot move to Ready For Startup if PSSR required but incomplete.
• Cannot close until all required actions are verified with evidence.
• Cannot close temporary change if removal/reversal plan is incomplete.
• Cannot close emergency change if 72-hour review is incomplete.

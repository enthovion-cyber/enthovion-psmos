================================================== CORE CONCEPTS
==================================================
Final Report: A compiled LOPA/SIL study report containing all technical analysis, assumptions, results,
recommendations, approvals, and evidence index.
Report Package: A bundled export that may include PDF report, calculation appendix, IPL validation
appendix, attachments index, approval snapshot, history export, and selected supporting files.
Official Report: A report version marked as official/approved and optionally published to Document Control.
Draft Report: A generated preview/report before final approval or before marking official.
Report Snapshot: Immutable snapshot of the data used to generate the report, including study status,
calculation version, SIL version, review approval snapshot, attachment index, and history event references.
Redacted Report: A permission-safe export that hides restricted data, restricted attachments, sensitive
comments, restricted history metadata, or confidential linked records.

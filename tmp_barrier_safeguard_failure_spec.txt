================================================== CORE PURPOSE
==================================================
This tab must answer:
• Which barriers, safeguards, controls, IPLs, SIS/SIFs, PSVs, alarms, interlocks, procedures, PPE,
containment systems, emergency controls, or administrative controls were expected?
• Which barriers were present, missing, failed, degraded, bypassed, overridden, late, ineffective, or
not tested?
• Did the barrier receive a demand?
• Did it respond correctly?
• Was it credited as an IPL in LOPA?
• Was it independent, effective, auditable, and maintained?
• Was a proof test, inspection, maintenance, or calibration overdue?
• What failure mode occurred?
• Was failure active, latent, human, equipment, design, management-system, procedural, or
maintenance-related?
• Which RCA root cause does it connect to?
• Which CAPA / MOC / MI / PSSR / LOPA / HAZOP / SIL follow-up is required?
• Is barrier analysis ready for review?
Important rule:
• Safeguard and IPL are not the same.
• A safeguard is any control or protection.
• An IPL is only a credited independent protection layer if it meets independence/effectiveness/
auditability criteria and is approved in LOPA/company configuration.
• Do not automatically treat every safeguard as an IPL.
